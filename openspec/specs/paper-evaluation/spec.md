# paper-evaluation Specification

## Purpose
Define how the planned replay separates allocation and ranking effects.

## Requirements

### Requirement: Predefine the planned replay
The manuscript SHALL document the four strata, fixed seed, matched baselines, and output denominators.

#### Scenario: Review evaluation
- **WHEN** the replay plan is read before execution
- **THEN** reviewers can distinguish the paired allocation comparison from the end-to-end policy comparison.
